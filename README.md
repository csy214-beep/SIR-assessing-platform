# SRI-assessing-platform（纯前端重构版）

🚀 **纯前端运行，无需服务器、数据库或 Python**

本项目是 [rstqxq/SIR-assessing-platform](https://github.com/rstqxq/SIR-assessing-platform) 的纯前端重构版本，原题目来自哈佛心理学系社区。所有评估逻辑、题库（普通版 60 题 + 增强版 600 题）均在浏览器端完成，结果通过 `localStorage` 保存在本地，充分保护隐私。

---

## ✨ 特性

- 🧩 **零依赖部署** – 只需浏览器打开 `index.html` 即可运行
- 📱 **响应式设计** – 完美适配手机、平板、电脑
- 🔒 **隐私优先** – 所有数据仅在本地浏览器存储，无需注册、不上传服务器
- ⚡ **即时结果** – 答完所有题目立即获得评分与个性化建议
- 🎲 **灵活选题** – 普通版固定 30/60 题；增强版 600 题题库智能随机抽题，覆盖 6 大心理学维度
- 💝 **人文关怀** – 结果页面提供鼓励语、温暖关怀和个性化建议
- 🔄 **本地历史** – 自动保存最近 50 次评估记录（仅存储在您的浏览器）

---

## 🚀 快速开始

### 最简单的方式

1. 下载本项目所有文件（`index.html`、`style.css`、`app.js`）
2. 直接用浏览器打开 `index.html` 即可开始评估

### 使用本地静态服务器（推荐，可避免部分跨域限制）

```bash
# 如果安装了 Node.js
npx serve .

# 或使用 Python
python -m http.server 8000

# 或使用 PHP
php -S localhost:8000
```

然后访问 `http://localhost:8000`。

## 🧪 评估版本

| 版本         | 题数                       | 说明                             |
|--------------|----------------------------|----------------------------------|
| 普通版·快速  | 30 题                      | 固定经典题库，约 10 分钟          |
| 普通版·深度  | 60 题                      | 固定全部普通版题目，约 20 分钟    |
| 增强版·快速  | 20 题                      | 600 题中随机抽选，约 5 分钟       |
| 增强版·标准  | 40 题                      | 随机抽选，约 10 分钟              |
| 增强版·深度  | 60 题                      | 随机抽选，约 15 分钟              |
| 增强版·全面  | 100 题                     | 随机抽选，约 25 分钟              |
| 增强版·专业  | 120 题                     | 随机抽选，约 30 分钟              |

增强版题库涵盖六大维度：投射理论、社会认知、身体意象、情绪调节、沟通表达、认知态度。
